# 展示书籍 / Demo books

将一本 EPUB 或 TXT 拖到易笺首页，或点击导入区选择文件。首次展示 EPUB 时建议用《爱丽丝梦游仙境》演示插图和目录，用《三國志演義》演示繁体阅读和繁简切换。两本 UTF-8 TXT 适合演示中文章回与英文分页。

| 展示文件 | 原作语言与用途 | 来源 |
| --- | --- | --- |
| 爱丽丝梦游仙境 - Lewis Carroll.epub | 英文 EPUB3，Arthur Rackham 插图和目录 | [Project Gutenberg #28885](https://www.gutenberg.org/ebooks/28885) |
| 三國志演義 - 羅貫中.epub | 繁体中文 EPUB3，章回与繁简切换 | [Project Gutenberg #23950](https://www.gutenberg.org/ebooks/23950) |
| 西遊記 - 吳承恩.txt | 繁体中文 UTF-8 TXT，长篇章回 | [Project Gutenberg #23962](https://www.gutenberg.org/ebooks/23962) |
| Pride and Prejudice - Jane Austen.txt | 英文 UTF-8 TXT，章节和分页 | [Project Gutenberg #42671](https://www.gutenberg.org/ebooks/42671) |

原作在美国属于公有领域。文件保留 Project Gutenberg 的原始内容及许可，仅调整本地文件名。若再分发，请保留原文件内的许可，并参照 [Project Gutenberg 许可](https://www.gutenberg.org/policy/license.html) 与当地法律。

本目录用于本地手动导入。Git 忽略书籍文件，默认 Vite 构建也不会把它们打进 Web 发布包。需要补齐展示样本时，可从上面的目录页重新下载同一格式。
